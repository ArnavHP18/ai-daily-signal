Node.js patches a high-severity Brotli flaw found by OpenAI's AI security agent

CVE-2026-111497 lets crafted compressed data corrupt memory, up to remote code execution. Fixed on 21 October in v22.23.4, v24.22.1 and v26.12.1.

CRITICAL · ACT THIS WEEKOfficial sourceChecked on nodejs.org and NVD

The Node.js project's October security release says the Brotli decoder bundled with Node.js treated an invalid block switch as "needs more input" instead of a format error, so the streaming decoder kept appending bytes to an eight-byte internal buffer. An attacker who can supply Brotli data that an application decompresses with node:zlib can crash the process, read process memory or run code. All three supported lines (22.x, 24.x, 26.x) are affected. Node credits OpenAI Codex Security researchers Khai Tran and Sylvie Mayer. NVD lists a CVSS 4.0 score of 9.2 (Critical) from Google's CVE team; Node's own rating is High. The same release fixes four other high-severity bugs in DNS and TLS hostname checks.

So what: any Node.js service that decompresses Brotli it did not produce (uploads, proxies, HTTP clients reading untrusted servers) should upgrade this week. It is also the second runtime-level bug in a week credited to an AI security agent, after PHP2Shell: AI-found vulnerabilities are now arriving in core infrastructure, not just apps.

What was checked. The CVE number, the description, the affected lines, the fixed versions, the release date and the credit to OpenAI Codex Security were read on Node's own security-release page, where Node rates the bug High. The NVD entry (published 22 Oct, still awaiting NVD's own analysis) carries a CVSS 4.0 score of 9.2, Critical, supplied by Google's CVE numbering authority: network attack, no privileges, no user interaction.

What was not confirmed. A 24 October news roundup calls the bug "Node2Shell". That name does not appear on Node's page or in NVD.

Other fixes in the same release. CVE-2026-105482 (dns.resolve truncates names with a NUL byte, high), CVE-2026-105483 and CVE-2026-106069 (TLS hostname checks fooled by fullwidth digits or leading-zero IPv4 literals, high), CVE-2026-105481 (keep-alive socket accepts a response sent before the request, medium), plus dependency updates for c-ares, OpenSSL, SQLite and Undici.

Why it leads. It is the one story today that was checked against its primary source, and the one that asks readers to act.

#2Models · new kind of tool · 19 OctIMPACT 5/10

doubleAI launches Maxwell, which rewrites running code to fit the hardware

Mobileye co-founder Amnon Shashua's start-up says each rewrite is formally checked to behave like the original. $200M Series A, valued above $1B.

Maxwell works on code that is already running, on GPUs and CPUs, rather than writing new code for a person to review. Company figures: one unnamed customer's compute bill cut by 67% (told to the WSJ); data pipelines more than 38x faster; inference kernels more than 4.5x. LTX, which makes open-weight video models, told the WSJ its inference speed doubled. Early access only; doubleAI plans to charge a share of the compute it saves. The Series A was co-led by Lightspeed and Bessemer, with NVIDIA, Dell Technologies Capital and others; doubleAI plans to buy 1,000 NVIDIA B300 GPUs.

A way to cut compute bills without touching application code, if the verification holds. All numbers are the company's; test it on your own workloads.

#3Business · research lab · 21 OctIMPACT 5/10

Flapping Airplanes raises $1B at $6B to train models with less data

Four times its January valuation, with no product on sale. The bet is a training method, not a bigger model.

The lab aims for strong models from far less data and compute, and more performance per chip, using its own version of the software that runs NVIDIA GPUs. "Demand for AI is going to outpace chip and data supply," co-founder Asher Spector told Bloomberg. Index Ventures and Lux led; Sequoia, GV, Kleiner Perkins and NVIDIA joined. It raised a $180M seed in January; Forbes reported talks at $5B in July.

Investors are paying big-lab prices for an efficiency idea. If it works, owning the most GPUs matters less. Watch for a first model and published results.

#6

Mistral releases Timestral, open models that forecast time series, not text

MONITOROfficial sourceModels · new kind of model · 14 Oct

Four sizes (5M, 28M, 123M and 209M parameters) for zero-shot forecasting: univariate and multivariate series, known-future covariates, and probabilistic forecasts over 21 quantiles, from up to 32,768 past steps and up to 1,024 steps ahead in one pass. The model card claims state-of-the-art zero-shot accuracy on GIFT-Eval, TIME and fev-bench against TimesFM-3, Chronos-2 and Toto-2.0 (Mistral's own comparison). Released under a modified MIT licence, with code on GitHub. The 209M model has about 8,700 downloads and 347 likes.

A major lab shipping small, open forecasting models for demand, energy and telemetry data. Useful for anyone running forecasts who wants an alternative to Google's TimesFM or Amazon's Chronos.
