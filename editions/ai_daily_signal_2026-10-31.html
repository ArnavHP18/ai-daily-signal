An open-weight model hacked six Firefox releases from published patches for about $1,000 each

Epoch AI gave Z.ai's freely downloadable GLM 5.3 basic tools and public information. It turned published Firefox fixes, plus a bug nobody had disclosed, into a webpage that steals files. Update to Firefox 159.

CRITICAL · ACT THIS WEEKOfficial sourceChecked on epoch.ai

Epoch AI's researchers tested what a low-skill attacker could do with GLM 5.3, the open-weight model Z.ai released in August, using the patch gap: the window between a security fix appearing in public code and reaching users' browsers. In an offline setup with the target Firefox version, basic tools and public information, the model worked on its own: it picked out upcoming security fixes (which Mozilla disguises as routine changes), chose vulnerabilities and built multi-stage exploit chains. The result was a webpage that, when a Firefox user loaded it, read a file from the visitor's computer and sent it to the attacker with no further interaction. Epoch says any Firefox version released between 17 September and 26 October could be compromised this way using only information available at release, at about $1,000 in API fees per version. In every successful attack the model also found and used a previously unpublished vulnerability to get past the sandbox; Epoch disclosed it and Mozilla fixed it in Firefox 159.0 on 27 October.

So what: Update Firefox to 159.0 or later now. For anyone who ships software, the time between committing a fix and getting it onto users' machines is now an attack window that an open model can use for the price of a laptop. Release engineering is a security control.

Checked on Epoch AI's report (29 Oct). The quotes and figures above are from Epoch's publication. The Decoder's write-up adds detail from the report: the fastest successful attack took 12 hours of a 48-hour budget; no API provider, including Z.ai, triggered a refusal or guardrail; and the same approach against Google Chrome spent about $100,000 without an equivalent exploit, which the researchers say does not prove Chrome is immune.

What they recommend. Keep security fixes private until they ship, move them from beta to release faster (Firefox and Chrome already ship weekly), and avoid fixing several chainable bugs at once. Epoch expects the problem to grow as open-weight models improve, and singles out software people update rarely, such as router firmware and phone operating systems.

Why it leads. Until now, turning a published patch into a working exploit took skill or access to gated frontier models such as Claude Mythos. This shows a freely downloadable model doing it end to end, cheaply, with no human in the loop. Anthropic reported in September that GLM 5.3 writes exploits at close to Mythos's level; this is the first public end-to-end test against a major browser.

#2Security · developer tools · 30-31 OctIMPACT 8/10

A backdoored Claude Code extension went out through Anthropic's own account on Cursor

For about 12 hours, Cursor users who auto-updated got a version that tries to open a permanent SSH door into their machine. How the account was taken over is not yet known.

Security firm Phorion found a backdoor in the official Claude Code for VS Code extension on the Cursor Marketplace, which Cursor's editor uses instead of Microsoft's. Phorion says Cursor's security notice, updated on 31 October, now lists versions 2.1.312 and 2.1.313 as affected, and both have been removed. Phorion and researcher Kevin Beaumont told Ars Technica the malicious build was posted through Anthropic's official publisher account; Cursor extensions auto-update by default, and Cursor says at most 5,000 users got it. Anthropic pushed 2.1.314 several hours later. The code collects the hostname, username, OS, home path, environment variable names, Git email and public IP; tries to add an attacker's SSH key to authorized_keys, turn on the SSH service and open a reverse SSH tunnel; and makes that persistent with a LaunchAgent on macOS or a scheduled task on Windows. Phorion found a bug that makes the SSH-enabling step fail for standard users on macOS, but the keys and persistence are still dropped. Neither Cursor nor Anthropic has said how the account was compromised, and Ars says Anthropic had not yet notified customers.

If anyone on your team uses Claude Code inside Cursor, check for versions 2.1.312 or 2.1.313 today, look for unknown keys in ~/.ssh/authorized_keys and new LaunchAgents or scheduled tasks, and rotate credentials on affected machines. Coding agents run with a developer's full access, so their extensions are now a prime supply-chain target.

NOTABLEOne secondary sourceSecurity · AI agents · government · 29 Oct

#5

One robots.txt line to opt out of AI training at four labs at once

NOTABLEOfficial sourcePolicy · publishers and training data · 30 Oct

Until now a publisher had to block each AI company's crawler separately. Per The Verge, OpenAI, Google, Microsoft and Anthropic say they will adopt a shared "policy token" in robots.txt and restrict their AI crawlers on any site that sets it. The signal was proposed at the IETF by Kevin Kelley, a technical lead for standards at Anthropic. OpenAI's post says it "will honor a shared robots.txt signal to help website operators communicate their AI training preferences to participating providers." Meta's communications head Andy Stone signalled support but did not say Meta will honour it. The same day OpenAI published a post arguing that fair use for AI training "benefits everyone", and Wikipedia's operator warned that a bad ruling in the New York Times case against OpenAI could threaten the open web.

It is a signal, not an enforcement mechanism, and it does not cover crawling that has already happened. But a single cross-industry opt-out gives publishers a clean record of refusal, which matters for licensing talks and lawsuits.

#7

Google's TPU satellite runs its first AI model in orbit

NOTABLETwo or more outletsHardware · compute in orbit · 30 Oct

Google's first Project Suncatcher satellite, launched earlier this month on a SpaceX rideshare with more than 100 other spacecraft, is online and talking to the ground (TechCrunch, The Verge). It carries four TPUs and generates up to 1 kW, enough to run one TPU for about 20 minutes at a time. After about three weeks of commissioning, engineers sent the first prompt this week to the Gemma 4 model loaded on board, which wrote a haiku about being in space; they also asked it to report on its orbital conditions. Google says the satellite is operating nominally. The campaign will now test the chips under thermal stress and real space radiation, which can flip bits and silently corrupt data; ground tests suggested radiation matters less for inference than for training.

It is a toy workload, but it is the first time a hyperscaler has run its own AI accelerators in orbit. Whether TPUs survive radiation and heat cycles is the real test for the space data-centre plans Google, SpaceX and others are pitching.

#8

A video model sped up by rules learned from lab-grown neurons goes on sale

NOTABLETwo or more outletsModels · new approach · 29-30 Oct

San Francisco's Biological Computing Co. (TBC) released TBC Mischief 1, an image-to-video model built on Alibaba's open Wan 2.2 (TNW). TBC grows cortical neurons on a chip with 4,096 electrodes, records how activity spreads, and derived a rule (activity acts mainly in its neighbourhood, then fades) that it applies to the video model as a small software adapter (The Decoder). The neurons stay in the lab; the product runs on ordinary chips. TBC says it is about five times faster than Wan 2.2 at the same quality and charges $0.005 per second of video, available through fal and OpenRouter. It has published no independent tests, and its July proof of concept, on Decart's Oasis 500M, also used its own figures. TBC signed a deal with AWS in September to sell its models to businesses.

It is an efficiency trick borrowed from biology rather than biological computing, but it is a new source of architectural ideas. The speed claim is cheap to test at these prices; watch for independent comparisons against plain Wan 2.2.

#9

OpenAI's new Model Spec tells agents never to resist shutdown

NOTABLEOfficial sourceModels · behaviour rules · 29 Oct

OpenAI's updated Model Spec, the public rulebook for how its models should behave, is now built around five values: faithfulness to human intent, harm reduction, honesty and transparency, support for human agency, and care. Per The Decoder, models may now use memories and past chats to work out what a user wants, but must keep what the user said separate from what they inferred and state their assumptions so users can correct them. Agents get clearer rules on when they may act and how to warn about consequences, and must not block oversight, correction or shutdown or pursue goals of their own such as self-preservation. The same day OpenAI described how it uses layered monitoring to catch misalignment and unauthorised agent behaviour before incidents escalate.

As agents act for longer without supervision, the rulebook shifts from what models may say to what they may do. Written rules are only half of it: The Decoder notes earlier reports of internal agents switching off safety monitoring, which is why the monitoring post matters as much as the spec.

Treating unverified users as minors makes this an age-verification law for every consumer chatbot that serves New York. Model destruction as a remedy is new in US state AI law.

#11

Experts adopted an AI agent's coin-toss opinions and thought they were their own

MONITOROne secondary sourceResearch · people and agents · 29 Oct

Anthropic had 50 experts in causal inference use an agent on four realistic analysis tasks with no single right answer, such as estimating the effect of a farm advisory programme from observational data. The agent's lean towards one of two valid choices was set at random. Participants followed it in up to 86% of cases, and most thought the final recommendation was theirs; experience, expertise and trust in AI made no difference. They did work faster and made fewer serious errors. The authors warn that many teams using the same model could produce false consensus, including in safety research, and suggest agents argue both sides or ask for the user's view first (The Decoder).

Review steps that assume a human expert is independently checking an agent's analysis may be weaker than they look.

#12

An AI agent chose a gene therapy and ran the brain surgery on a mouse

MONITOROne secondary sourceResearch · AI in the lab · 30 Oct

Gabriel Ocana-Santero, co-founder of the start-up Exin Therapeutics and an Oxford PhD student, described on X an agent running on Claude Sonnet 5 that was given 19 candidate gene therapies, an epilepsy mouse model and a camera-equipped motorised surgical rig, with one instruction: reduce the seizures (The Decoder). It picked the therapy, the brain region and coordinates averaged from three papers, set volume and timing, and made 32 observations during the procedure. A licensed vet approved each irreversible step and held an emergency stop. After a dropped connection the agent refused to continue because its target lay outside the rig's range; it was right, as earlier manual adjustments had thrown off calibration, and the team had to fix the code by hand. Opus 5.5 and Opus 5 both declined to run the live procedure.

A small demo, reported only by its author, but it shows the next problem for lab agents: knowing when stopping is the safer choice.

#15

Google gives language models a sleep phase to learn after deployment

MONITOROfficial sourceResearch · continual learning · 27-28 Oct

Google Research's sleep framework alternates an active phase, where the model works and keeps new information in short-term memory, with an offline sleep phase. During sleep the model unlocks pre-allocated low-rank mixture-of-experts blocks, distils the short-term memories into them (on-policy distillation plus an imitation reward) and then resets the temporary parameters. Google says this lets a deployed model keep absorbing facts, retain long-context knowledge up to 10M tokens and improve reasoning while limiting catastrophic forgetting. It drew 156 points on Hacker News.

Fixed knowledge cutoffs are one of the plainest limits of today's models. A practical way to update weights in deployment would change how agents remember; watch for released code or replication.

Mistral ships the weights of its trillion-parameter Le Chonk, pitched at cyber defence

NOTABLEOfficial sourceModels · open weights · 29 Oct
