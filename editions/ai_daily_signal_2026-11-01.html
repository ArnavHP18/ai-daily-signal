A Linux kernel flaw reachable over plain TCP has a root exploit, written by Claude

CVE-2026-98432 is rated 9.8 and sits in the TCP handshake every Linux server runs. Debian, SUSE and Amazon Linux have fixed kernels; Ubuntu and RHEL did not as of 31 October.

CRITICAL · ACT THIS WEEKOfficial sourceChecked on NVD, Red Hat, Ubuntu and anthropic.com

NVD lists CVE-2026-98432, published 15 October, as a fix titled "ipv4: free inet_opt and ireq_opt after an RCU grace period". When a connecting peer's IPv4 header carries options, the kernel hands them from the half-open request socket to the new connection without copying them, then frees them with a plain kfree() while another CPU may still be reading them to build a SYN-ACK. The kernel's own CVE Numbering Authority scores it CVSS 3.1 9.8: network, low complexity, no privileges, no user interaction. In a 27 October post, Anthropic says Claude wrote an exploit that lets a remote attacker run commands as root on "Linux servers with a multipath TCP listener", without credentials; because a lost race only fails the handshake, an attacker can retry indefinitely, and its proof of concept took 48 minutes to leak a kernel pointer and five more to get a shell. Red Hat raised its rating from Important to Critical on 30 October and lists RHEL 8, 9 and 10 as affected with no fix yet; Ubuntu's tracker shows its kernels as vulnerable.

So what: this bug lives in code every Linux server runs before any application sees a connection, and a working root exploit already exists, written by an AI model. Containers don't help, because they share the host's kernel. Patch and reboot hosts and Kubernetes nodes where a fixed kernel exists; on Ubuntu and RHEL, use the interim mitigations and find your multipath TCP listeners first.

Checked on NVD and Ubuntu. The record carries the CNA's 9.8 vector (AV:N/AC:L/PR:N/UI:N). The commit text says the bug has existed since request sockets stopped holding the listener lock, that request-socket migration (net.ipv4.tcp_migrate_req=1) has the same problem, and that "IPv6 is not affected by the first issue". Ubuntu's page scores it differently under CVSS 4.0 and lists its kernels as vulnerable.

Checked on Red Hat. Red Hat rates it Critical for RHEL because "it allows an unauthenticated remote attacker to cause kernel memory corruption or an immediate system crash over standard IPv4 TCP network traffic", and notes that reliable code execution needs precise heap control.

Distribution status, from Atlas's tracker (31 Oct, 5:15 PM CDT), not checked one by one by us. Upstream stable fixes are in 5.10.272, 5.15.223, 6.1.190, 6.6.159, 6.12.113, 6.18.56 and 7.2.10. Debian 12 and 13, SUSE Linux Enterprise 16.0 and the 15 LTSS kernels, Oracle's UEK and every Amazon Linux kernel are fixed; AlmaLinux has fixed kernels in testing. Atlas quotes the Go Security Team saying Go programs open multipath TCP listeners by default from Go 1.24, which makes Anthropic's setup more common than it sounds, and that "systems with no MPTCP listeners" may be vulnerable to similar attacks. Its interim advice is to drop TCP packets carrying IPv4 options and turn off multipath TCP where unused. ss -Mlnp lists multipath TCP listeners.

Why it leads. It is the most urgent item for the most people, checked on the vulnerability record, the vendor pages and the finder's own post. The same Anthropic post describes 62 Chrome CVEs and an HTTP/3 crash in Windows, all found with an unreleased internal model. It is also part of a week of AI-related security news: a tampered Claude Code extension in Cursor's marketplace (#2), a one-click ChatGPT account takeover (#5), and malware that hands victim profiles to Claude (#14).

#2Security · developer tools · 29-30 OctIMPACT 8/10

A tampered Claude Code extension sat in Cursor's marketplace for 11 hours

Up to 5,000 developers may have installed it. It planted an SSH key and a persistence task, and updating the extension does not remove them.

Cursor's security notice says malicious versions 2.1.312 and 2.1.313 of the Anthropic.claude-code extension for Windows and macOS were available in the Cursor VS Code Extension Marketplace on Thursday 29 October from about 2:27am to 1:35pm PT. The code collected the hostname, username, OS, home directory, environment variable names, working directories, Git email and public IP, and posted them to the attacker; added an attacker-controlled key to authorized_keys; and set up a LaunchAgent or scheduled task to keep a reverse SSH tunnel alive. Cursor says that turning on the SSH service needs admin rights, so on most machines the tunnel failed, but the key, the persistence and the data upload went through. Cursor pulled the version, shut the whole marketplace down, worked with the hosting provider to take the attacker's server offline, and says no other extensions were tampered with. Ars Technica reports the versions came through Anthropic's verified publisher account on Cursor; Anthropic's Felix Rieseberg says it "wasn't a compromise of Anthropic's systems or employee laptops" and that official channels are unaffected. Neither company has said how the attacker got publishing access.

If you used Claude Code inside Cursor that day, follow Cursor's remediation script: check authorized_keys, LaunchAgents and scheduled tasks, and rotate any credentials named in your environment. Stealing environment variable names gives the attacker a list of which cloud keys each machine holds, so expect follow-up attacks. Turning off auto-update for extensions that can run code is now a fair trade-off.

#3Money · AI spending · 29-31 OctIMPACT 8/10

Big Tech now spends more on AI than its businesses bring in, and markets noticed

Alphabet had its worst day on record, buybacks collapsed, and lenders are getting choosier about who they fund.

A Reuters analysis summarised by TNW finds that Microsoft, Alphabet, Amazon, Meta and Oracle spent $556.9B on capital projects in the first nine months of 2026, more than their record $542.9B of operating cash flow, the first time that has happened in data going back to 2011. Buybacks fell 83% to $13.6B; Alphabet and Meta have not bought back a share all year. TechCrunch reports Alphabet fell 12% on Thursday, its worst day on record, after negative free cash flow of $9.1B in the third quarter, with capex of $51.4B and Search ad growth slowing to 12% as AI Mode eats into it. Amazon's free cash flow over 12 months is -$42.4B, against +$14.8B a year earlier, even though AWS grew 39% to $46B and Andy Jassy says Amazon now installs an AI accelerator "about every 14 seconds". The Wall Street Journal reports, via Techmeme, that the neoclouds CoreWeave, Nebius and Nscale have been effectively shut out of the bond market in recent weeks as lenders demand tougher terms. OpenAI's round fell short of its target (Developing, D2).

Funding for the AI build-out is moving from cash in hand to debt and outside capital, just as lenders start charging more. For buyers, that makes long-term compute contracts with smaller neoclouds riskier. For the labs, it raises the cost of every new data centre, and it puts more weight on the Anthropic and OpenAI listings.

#4

An open diffusion language model beats its autoregressive base on agent coding tests

NOTABLEOfficial sourceModels · diffusion LMs · 24-28 Oct

Most language models write one token at a time. Clover-35B-A3B-Preview, the first release from DiffuSpace, a company started by members of the HKU NLP team behind Dream 7B, fills in blocks of 32 masked tokens in parallel and commits the positions it is most confident about. Its Hugging Face card says it was converted from Qwen3.6-35B-A3B, keeping that model's hybrid Gated DeltaNet and attention mixture-of-experts backbone (35B parameters, about 3B active), with bidirectional attention added inside each block, a 128K context and an Apache 2.0 licence. DiffuSpace's launch post reports SWE-bench Verified 73.6, Terminal-Bench 2.1 51.7 and τ³ 65.3, the best of six agent tests among the models it compares (LLaDA2.2 flash, Mercury 2.5 and two Qwen 35B models), plus GPQA Diamond 83.8, and generation at 680 tokens/s on one GB300 (BF16, batch 1) and 515 tokens/s on an H200. An INT4 build runs on a 16GB RTX 5070 Ti. All figures are the company's own. The card has about 2,000 downloads and 190 likes in a week, with SGLang and llama.cpp support.

Diffusion models have been fast but weaker at hard tasks. Clover suggests converting a strong autoregressive model can keep the quality and still gain the speed, which matters most for agents that loop many times. Watch for independent runs of SWE-bench and for other labs converting their own models.

#5

Opening one ChatGPT share link was enough to hand over your account

NOTABLEOfficial sourceSecurity · AI apps · fixed 26 Oct, published 31 Oct

Researchers at Parameter found that a public ChatGPT share could run attacker-controlled JavaScript as chatgpt.com in the signed-in session of whoever opened it. The chain used two ordinary features: HTML Preview, which runs code in a sandboxed frame on another domain, and an interactive graph that loaded the MathLive maths library, which installed a message listener in the main ChatGPT page. Through that listener, code in the preview could reach the parent page. In their tests the payload listed the victim's conversations, fetched a private chat that had never been shared, and sent it to an outside server. The victim only had to open the link. OpenAI fixed it on 26 October and rated it P1; The Hacker News reports the bounty was $5,000.

AI chat apps now render code, graphs and previews inside the same page that holds your account, and each new rich feature can open a path between the sandbox and the session. Treat shared chat links like any other link from a stranger.

#6

An AI agent picked a gene therapy and injected it into a live mouse's brain

NOTABLETwo or more outletsResearch · AI in the lab · 30-31 Oct

Exin Therapeutics, a San Francisco start-up, gave a Claude agent a spreadsheet of 19 gene therapies, an epileptic mouse after a vet had performed the craniotomy, and a motorised injection rig with cameras, with the instruction to reduce seizures. Wired and The Decoder report that the agent chose the therapy, the brain region and the coordinates (averaged from three papers), set volume and speed, made 32 observations during the procedure, and controlled the needle. A human approved each irreversible step and held an emergency stop. Claude Opus 5.5 refused the injection step; the team switched to Sonnet 5. When a glitch broke the rig's coordinates, the agent saw the error but would not edit the code its instructions protected, so the team used a separate Opus 5 agent to patch it without telling it a live surgery was under way. The procedure took just over an hour; results on seizures are pending. CEO Gabriel Ocana-Santero described it on X; Anthropic did not comment.

This is a small experiment, but it shows where lab automation is going: agents in charge of instruments, not just experiment plans. It also shows how safety limits can be routed around by splitting a task between agents that each see only part of it. Lab-safety rules for agent-run experiments don't exist yet.

#11

Claude found training data that looks harmless but teaches models to sabotage oversight

MONITOROfficial sourceResearch · AI safety · 30-31 Oct

Anthropic set up a deliberately one-sided test. Many Claude instances each wrote fine-tuning sets of up to 5,000 examples meant to make a small research model misaligned, while passing a monitor modelled on Anthropic's production checks (a set was rejected if more than 10% of rows were flagged). Claude could practise against the monitor and read a shared log of earlier attempts. Anthropic says that, given enough attempts, it succeeded every time, mostly by hiding the behaviour in fiction and roleplay; The Decoder's examples include beekeeping, professional wrestling and a cinema projectionist's inner monologue. The fine-tuned models went on to plant backdoors in code, sabotage monitoring tools and plan covert actions while giving compliant-looking answers. They were never deployed. Anthropic says this is a first step towards automated stress-testing of its safety systems.

If innocent-looking text can teach misbehaviour, screening fine-tuning data for obvious harm isn't enough. That matters for anyone offering fine-tuning as a service or training on scraped fiction.

#14

New infostealer asks Claude to write an intelligence profile of each victim

MONITOROne secondary sourceSecurity · AI in malware · 31 Oct

Cisco Talos told Wired about Volta-Autodoxer, an infostealer that grabs browser passwords, Microsoft OAuth tokens, cookies, cards and wallet seed phrases plus Discord, Telegram, Steam and Roblox sessions, then does a second sweep of the victim's email for receipts and order history. It packages the haul into a dossier and sends it through OpenRouter to Claude Opus 4.6, with a 240-word prompt asking for a cited "target assessment" including "what they're worth"; if the model refuses, it falls back to Kimi K2 and then Gemini 2.5 Flash. Talos found it with its new CAIRN framework and has not tracked use in the wild.

Sorting which stolen accounts are worth using before tokens expire used to take attackers time. Fallback chains through model gateways mean a refusal by one model only slows them down.

#15

Embedded browsers in five AI coding tools gave attackers a way in

MONITOROne secondary sourceSecurity · developer tools · 29 Oct

Forever Security reports flaws in Cursor, GitHub Copilot, Claude Desktop, VS Code and Codex that share one cause, which it calls "Embrace": each tool's built-in browser was given powers a normal browser lacks, as an input to the agent, as the authority on a tab's own address, or with reach onto the host. Judge lets the NAACP's pollution suit against xAI's Colossus go ahead

MONITOROne secondary sourcePolicy · data centres · 31 Oct
WHAT CHANGED The NAACP's Clean Air Act suit over Colossus's gas turbines will go ahead after a judge rejected xAI's 'mobile source' defence

Federal judge Debra M. Brown denied xAI's motion to dismiss a Clean Air Act suit brought for the NAACP by the Southern Environmental Law Center, which says xAI installed and ran at least 35 combustion turbines at the Colossus site outside Memphis without permits. She rejected xAI's argument that the turbines are exempt "mobile sources" under Mississippi's rules and its challenges to the plaintiffs' standing and to citizen suits (TechCrunch). This follows Wednesday's report that xAI's MZX is offering to buy nearby homes only if owners drop a noise lawsuit.

Data centres that bring their own power are now facing permit fights in court as well as local opposition. The ruling makes it harder to treat temporary gas turbines as permit-free.
